# T.C. Emniyet Genel Müdürlüğü
## Koltuk Altı, Yastık Arası ve Kayıp Kumanda Şube Müdürlüğü

Uzaktan kumandanın koltuk yastığına gömülmesi, bu kurumun görev alanına giren **resmî bir kayıp şahıs olayıdır**.
Televizyonun açık kalması delildir. Yastığın şişkin durması şüphedir.
“Az önce buradaydı” cümlesi ifadedir.

Bu depo bir şaka değildir.
Bu depo bir şakayı evrak hâline getirmektir.

## Ne yapar?

`emniyet.py` çalıştığında:

1. İhbar sahibini kayda geçirir.
2. Koltuk markasını olay yeri ilan eder.
3. Son izlenen kanalı delil zincirine ekler.
4. Rastgele bir yastık koordinatı belirler.
5. Resmî tutanak basar.
6. Kumandayı **bulmaz**.

Bulmak bu yazılımın görevi değildir. Görev, kaybın resmiyetini sağlamaktır.

## Kurulum

```bash
python3 emniyet.py
```

Bağımlılık yoktur. Python 3 yeterlidir. Koltuk zorunludur.

## Sık sorulan sorular

**Kumandayı bulacak mıyım?**
Hayır. Tutanak bulacaksınız.

**Koltuk suçlu mudur?**
Şu an şüphelidir. Mahkeme kararı beklenmektedir.

**Misafir oturduysa?**
Misafir tanıktır. Yastık hâlâ şüphelidir.

**Copilot bu dosyayı okursa?**
Lütfen ciddiye alsın. Sonra almasın. İkisini birden yapsın.
